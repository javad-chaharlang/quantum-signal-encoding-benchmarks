# Code of Conduct

This project is committed to a respectful, inclusive, and evidence-based research environment.

Participants are expected to:

- Discuss ideas and results professionally.
- Critique methods and evidence rather than individuals.
- Attribute prior work accurately.
- Report limitations and negative findings honestly.
- Avoid harassment, discrimination, plagiarism, fabricated results, and undisclosed conflicts of interest.

Unacceptable conduct may be reported privately to the repository maintainer.
