# Security Policy

This repository is research software and is not currently intended for safety-critical or production deployment.

## Reporting a vulnerability

Please do not disclose an exploitable vulnerability in a public issue. Contact the maintainer privately with:

- A description of the issue
- A minimal reproduction
- Affected versions
- Potential impact
- Suggested mitigation, if available

Do not include private datasets, credentials, tokens, or client information in reports.
